# Belajar Golang

Repo latihan pribadi buat belajar Go dari dasar sampai production-ready.
Setiap folder = 1 exercise, tiap exercise punya README kecil isi apa yang dipelajari.

## Aturan Main

- Commit walau kodenya jelek atau belum kelar. Progress > perfect.
- Minimal 5 menit sentuh repo ini per hari (buka, ketik 1 baris, commit).
- Commit message jujur — boleh nulis "masih bingung X" kalau emang masih bingung.
